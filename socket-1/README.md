# ネットワークプログラミング1　課題4-2
## 動作内容
サーバーとしりとりができるプログラム


クライアントとサーバーで接続を行った後、サーバーから単語の入力が求められる。入力はひらがなのみを受け付ける。

漢字やカタカナ、アルファベットなどを使用した場合は、もう一度ひらがなで入力し直すように促す。

サーバーやクライアントが「ん」で終わる単語を出した場合、プログラムを終了する。しりとりの途中で「q」を入力しても終了する。

Macで動作確認を行ったが、Windows環境ではShift-JISモードにしないと動作しない可能性がある。

## 動作結果
動作結果は以下のとおりである。

### Server側
```
ートを入力してください(5051など) → 5051
localhostの5051番ポートで待機します
接続しました。相手の入力を待っています......
メッセージはabc
メッセージはhello
メッセージはりんご
メッセージはもも
メッセージはじたい
メッセージははんむらびほうてん
```

### Client側
```
Serverで指定したポートを入力してください→ 5051
localhostの5051番ポートに接続を要求します
接続されました
しりとりをします。
ひらがなかアルファベットで単語を入力してください。
濁点・半濁点は無視してOK
q で終了
abc
ひらがなの単語を入力してください。
hello
ひらがなの単語を入力してください。
りんご
りんご ですね。では次の言葉は、 こどもです。
もも
もも ですね。では次の言葉は、 もみじです。
じたい
じたい ですね。では次の言葉は、 いろはです。
はんむらびほうてん
はんむらびほうてんですね。「ん」がついたのであなたの負けです！
しりとりを終了します。
```
